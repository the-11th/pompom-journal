Discord inbox setup

Add selected DM messages to your journal using Discord’s own message action. Imported text and timestamps work offline; capturing new messages uses a small private HTTPS inbox.

  1. Create your own application in the Discord Developer Portal. Enable User Install with the applications.commands scope.
  2. Host the included private receiver with a persistent data volume. Set your application public key, your Discord user ID, and a private receiver token.
  3. Set the application’s Interactions Endpoint to your receiver’s /interactions address, then register the “Add to Datapom” command using the included setup script.
  4. Return to Photos & places Settings, enter the receiver details, and install the action in Discord.

A private message link alone cannot supply its contents. This integration captures only messages you select. Photos can be imported separately.
