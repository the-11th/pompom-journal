# QA journal tags

Fixed and installed on the Samsung QA app on September 10, 2026.

- Saving a new tag shows a selected chip and clears the input. Permanent chips
  use regular text; temporary chips use the existing italic treatment.
- Permanent tags are available, initially unselected, on other days while
  offline. Temporary tags remain on the entries where they are selected.
- An independent tag outbox preserves permanent additions through later
  autosaves, restarts, retries, and delayed acknowledgements. Autosave retains
  its normal behavior and never commits unfinished task lines.
- Confirmed tags follow later Mac archives. Older explicit phone additions are
  recovered without repeatedly recreating acknowledged tags.
- Save replies preserve newer typing; conflict resolution renders accepted tags.

Validation: 1,245 Python tests; 375 full JS/browser tests plus a new promotion
check; final 60 shared/mobile editor checks; 109 Android unit tests; targeted
tag checks and the full isolated Samsung storage/WebView suite. Mobile tag
layout was visually checked. Existing QA entries and production data were kept.
